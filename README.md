# Calculadora de IMC - Flutter 🚀

Este projeto é uma aplicação mobile desenvolvida em **Flutter** para o cálculo do Índice de Massa Corporal (IMC). O objetivo principal foi reproduzir fielmente o protótipo fornecido, garantindo uma interface amigável e uma lógica de cálculo precisa.

## 📱 Funcionalidades
- **Cálculo em Tempo Real:** Resultados atualizados dinamicamente usando Stateful Widgets.
- **Seleção de Gênero:** Interface interativa para escolha entre Masculino e Feminino.
- **Validação de Erros:** Tratamento de entradas inválidas ou campos vazios para evitar falhas no app.
- **Categorias de IMC:** Drawer/Modal informativo exibindo as classificações oficiais de saúde.

## 🛠️ Tecnologias Utilizadas
- [Flutter](https://flutter.dev/) - Framework UI.
- [Dart](https://dart.dev/) - Linguagem de programação.

## 📐 Design
A interface foi construída seguindo rigorosamente o protótipo, focando em:
- Bordas arredondadas e sombras suaves.
- Tipografia limpa e pesos de fonte variados para hierarquia visual.
- Cores consistentes com o guia de estilo (Azul #5EBCE5).
